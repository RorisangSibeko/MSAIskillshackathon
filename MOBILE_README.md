# SafeWayAI Mobile App

SafeWayAI is an AI-powered emergency detection platform that provides safe routes to destinations, detects danger in real time, and allows users to report incidents.

## Features

- **AI Monitoring**: Real-time analysis of surroundings to detect potential dangers
- **Emergency Alerts**: Instant notifications when danger is detected
- **Incident History**: View past incidents in your area
- **Manual Reporting**: Report incidents you witness
- **Safe Navigation**: Find the safest route to your destination
- **Emergency Chat**: Contact emergency services directly through the app
- **Emergency Contacts**: Alert loved ones when you're in danger

## Installation

### Android

1. Download the APK file from the releases section
2. Enable "Install from Unknown Sources" in your device settings
3. Open the APK file to install the app

Alternatively, run the installation script if you have the device connected to your computer:
```bash
./install_safewayai.sh
```

### iOS

The iOS version is available through TestFlight. Contact the development team for an invitation.

## Getting Started

1. Launch the app and sign in with your credentials
2. Grant the necessary permissions (location, camera, etc.)
3. Set up your emergency contacts
4. Start using the app to navigate safely

## Permissions

The app requires the following permissions:
- Location (for navigation and incident reporting)
- Camera (for incident documentation)
- Microphone (for emergency communication)
- Contacts (for emergency contact setup)
- Storage (for saving incident reports)
